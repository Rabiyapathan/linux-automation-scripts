# Linux Automation Scripts

A collection of Linux automation scripts for system administration, monitoring, and task automation.

## Current Scripts

### 1. system-info.sh
Displays:
- Hostname
- Current user
- Current date and time
- Linux kernel version

- Bash Scripting
- Linux (Fedora)
- Git & GitHub
